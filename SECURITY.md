# Security policy

Please report vulnerabilities privately — do not open public issues. Until a dedicated address is published, use GitHub private vulnerability reporting: https://github.com/romainalcon/veyra/security/advisories/new

We aim to acknowledge reports within 3 business days and to publish fixes in a patch release with a CHANGELOG entry. Supported versions: the latest minor release.

See `docs/SECURITY_REVIEW.md` for the current security model.
