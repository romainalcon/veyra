# Veyra — Architecture

## Runtime
- Laravel 13 modular monolith serves an Inertia 3/Vue 3 application.
- MariaDB persists users, organizations, monitors, current states, checks, incidents and notifications.
- Redis hosts queues, cache and coordination primitives.
- Laravel Scheduler claims due monitors; a durable outbox publishes jobs to Redis.
- Horizon executes all probes and asynchronous processing (no separate probe agent).
- Reverb broadcasts status/incident changes; HTTP remains authoritative.

## Domain layout
```
app/Domain/
  Identity/        Fortify actions, validation concerns, RegistrationGate, DeleteUser, Impersonation contract (ADR-038)
  Organizations/   Actions, DTOs, Enums (OrganizationRole), Models, Notifications, Services
  Entitlements/    Entitlements contract, Community implementation (no limits), Quota (ADR-029)
  Extensions/      Extension points such as OrganizationNavigation (ADR-030)
  Monitoring/      Probes, outbox, confirmed state, statistics
  Incidents/       Incidents, timeline events, public updates
  Notifications/   Channels, deliveries, reminders
  Maintenance/     Planned maintenance windows and state transitions (Sprint 6)
  StatusPages/     Public status pages, snapshot, custom domains (Sprint 6)
  Realtime/, System/
app/Http/{Controllers,Requests,Middleware}/
app/Policies/
app/Models/User.php            # kept in the conventional location (Fortify/auth)
resources/js/{pages,components,composables,layouts,lib,types}/
resources/js/{actions,routes,wayfinder}/   # generated by Wayfinder, not committed
extensions/<name>/   # optional extensions cloned from their own repositories, git-ignored (ADR-030)
```

## Tenancy
- Tenant routes: `/o/{organization:slug}/…` behind `auth`, `verified` and `ResolveOrganization` (404 for non-members), with scoped child bindings.
- Authorization: `OrganizationPolicy` (registered with `#[UsePolicy]`), capabilities from `OrganizationRole`.
- Inertia shares only whitelisted props: `auth.user` (id, name, email, verification), `organizations` (id, name, slug), `currentOrganization` (with `can.*` flags).
- Broadcasting: private channel `organizations.{organizationId}` authorized for members only (`routes/channels.php`). The client reloads props over HTTP after reconnecting.

## Public API (Sprint 19, ADR-044)
- `/api/v1/…` (`routes/api.php`): stateless, JSON, `auth:api` (organization API tokens, `ApiTokenAuthenticator`), `ResolveApiOrganization` (the token's organization becomes the `{organization}` route parameter before bindings, with scoped bindings), `throttle:api`. Controllers in `app/Http/Controllers/Api/V1`, resources in `app/Http/Resources/Api/V1`; they reuse the interface's Form Requests, Policies (`OrganizationActor`) and Actions. Reference: `docs/api/openapi.yaml`.

## Public surface (Sprint 6)
- `/status/{slug}` and verified custom domains (`ServeStatusPageForCustomDomain`, global middleware) render public status pages without session, from a cached whitelisted snapshot; they poll over HTTP and never subscribe to Reverb.

## Queue separation
- `probes`: HTTP checks; strict timeout and concurrency controls.
- `incidents`: state transitions and incident events.
- `notifications`: email, Discord, Slack, ntfy, Gotify, Telegram, Microsoft Teams, PagerDuty and outgoing webhook delivery.
- `maintenance`: aggregation and batched retention.

## Deployment
- Community: `compose.yaml` with app, Nginx, MariaDB, Redis, scheduler, Horizon, Reverb.
- Private: Vito Deploy with PHP-FPM/Nginx, MariaDB, Redis, supervised Horizon/Reverb and scheduler cron.
- Same application code; environment configuration differs.

## Architectural boundaries
- Use domain services/actions; no business logic in controllers.
- Cloud entitlements behind an interface, never a dependency from the Community core: the core binds `CommunityEntitlements`; an extension rebinds `Entitlements` (ADR-029).
- Probe workers are Laravel jobs, but must have outbound network controls.
- Optional extensions depend on the core through documented extension points only (pages, translations, navigation, entitlements, `Impersonation`, `OrganizationDeleting`, `RaiseMonitorIntervals`); the core never references extension code (ADR-030).
